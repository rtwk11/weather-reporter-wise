# WeatherWise

A responsive weather dashboard built with HTML, CSS and JavaScript.

## Features
- Search any city
- Current temperature
- Humidity
- Wind speed
- Feels-like temperature
- Weather condition
- Rain probability
- 7-day forecast
- Responsive design
- Weather API integration
- Error handling

## Technologies
HTML5, CSS3, JavaScript, REST API

## API
Open-Meteo is used for city search and weather data.

## Run in VS Code
Open this folder in VS Code, install the Live Server extension, then right-click `index.html` and choose **Open with Live Server**.
